\# 🛒 Online Laptop Store



A web-based \*\*Online Laptop Store\*\* developed using PHP and MySQL. The project provides a simple and user-friendly platform where customers can browse laptops, view product details, manage their shopping cart, and place orders.



\## ✨ Features



\### 👤 User Features



\* User registration and login

\* User dashboard

\* Browse available laptops

\* View laptop products

\* Add products to cart

\* Update cart items

\* Checkout and place orders

\* Contact page

\* User logout



\### 🔐 Admin Features



\* Admin dashboard

\* Manage users

\* Manage laptop products

\* Manage customer orders



\### 🛍️ Shopping Features



\* Laptop product listing

\* Product images

\* Shopping cart

\* Checkout system

\* Order management



\## 💻 Technologies Used



\* \*\*Frontend:\*\* HTML5, CSS3

\* \*\*Backend:\*\* PHP

\* \*\*Database:\*\* MySQL

\* \*\*Server:\*\* Apache / WAMP Server

\* \*\*Database Management:\*\* MySQL

\* \*\*Editor:\*\* Visual Studio Code

\## 🗄️ Database



The project uses \*\*MySQL\*\* for storing application data.



Database name:



```text

laptop\_store

```



The project can be configured through:



```text

includes/db.php

```



> Make sure your database credentials are configured correctly before running the project.



\## ⚙️ Installation \& Setup



\### 1. Clone the repository



```bash

git clone https://github.com/riyamistry27/online-laptop-store.git

```



\### 2. Move the project



For WAMP Server, place the project inside:



```text

C:\\wamp64\\www\\

```



The final path should be:



```text

C:\\wamp64\\www\\online-laptop-store

```



\### 3. Start WAMP Server



Start:



\* Apache

\* MySQL



\### 4. Create the database



Open MySQL/phpMyAdmin and create:



```text

laptop\_store

```



Import your project database SQL file if available.



\### 5. Configure the database connection



Open:



```text

includes/db.php

```



Update the database connection details according to your local MySQL configuration.



\### 6. Run the project



Open your browser and visit:



```text

http://localhost/online-laptop-store/

```
